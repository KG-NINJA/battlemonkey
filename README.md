# BattleMonkey VR

Three.js で作成した単一 HTML のターン制 3D 戦術ゲームです。  
GitHub Pages では `docs/` を公開フォルダとして使います。

## 公開に使うファイル

- `docs/index.html`
- `docs/.nojekyll`

## GitHub Pages 公開手順

1. このフォルダ一式を GitHub リポジトリにアップロードする
2. GitHub の `Settings` -> `Pages` を開く
3. `Build and deployment` の `Source` を `Deploy from a branch` にする
4. Branch を公開したいブランチに設定する
5. Folder を `/docs` に設定する
6. 保存する

公開後、数分で `docs/index.html` の内容が Pages URL で遊べます。

## ローカル確認

`docs/index.html` をブラウザで開くだけで動作します。
